## 3주차
### 셸 스크립트
- 자동화를 위한 도구
- .sh 확장자 파일로 자동화
- 셸 스크립트를 만들고 난 뒤 권한 추가 후 실행

|코드|설명|
|---|---|
|#! `프로그램`|어떤 인터프리터로 실행할 지 os에 알려줌|
|$0|현재 실행하는 스크립트의 이름, 경로|
|$1, $2...|첫번째 인자, 두번째 인자...|
|$(`명령어`)|괄호 안의 명령어를 실행 후 실행한 명령의 표준 출력을 넣기|
| \|\| |논리 or, 앞 명령 실패 시 뒤 명령 실행|
|exit `상태코드`|종료하고 상태코드를 남김 0은 정상 1은 실패|
|exec `프로그램` `파일`|실행 중인 인터프리터 대체 후 파일 실행(PID유지)|
