## 명령어 정리
1. 기본 리눅스 명령어 정리
    |명령어|의미|
    |:---:|:---:|
    |mkdir|디렉토리 만들기|
    |rmdir|빈 디렉토리 삭제|
    |cd|디렉토리 이동|
    |pwd|디렉코리 확인|
    |ls|파일 및 폴더 목록 확인|
    |sudo apt update|패키지 목록 최신 상태로|
    |sudo apt install `패키지 이름`|패키지 설치|
    |sudo apt remove `패키지 이름`|패키지 삭제|
    |chmod `권한` `파일 이름`|권한 수정|
    |touch `파일 이름`|파일 생성|
    |cat `파일 이름`|파일 확인|
    |rm `파일 이름`|파일 삭제|
    |history|이전 명령어 기록 확인|
2. git 명령어 정리
    |명령어|의미|
    |:---:|:---:| 
    |git --version|깃 버전 확인|
    |git config --list|깃 설정 확인|
    |git init|깃 초기화|
    |git status|깃 현재 상태 확인|
    |git add .|수정한 모든 파일을 무대에 올림|
    |git commit -m `"메세지"`|깃 버젼 저장(커밋)|
    |git log|커밋 기록 확인|
    |git switch -c `브랜치 이름`|브랜치 만들기|
    |git switch `브랜치 이름`|브랜치 변경|
    |git branch|브랜치 확인|
